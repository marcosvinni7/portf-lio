- `index.html`, `style.css`, `script.js`: site estático sem dependências externas. O hero contém um dashboard-resumo com status reais do rascunho.

- `docs/quality-gates.md`: resultados das verificações estáticas e gates que ainda dependem de revisão/testes externos.

## Executar localmente

Abra `index.html` no navegador. A navegação usa links internos; o JavaScript atualiza o ano do rodapé.

## Testes e Quality Gates

Os checks de código passaram (10/10), incluindo a presença e o conteúdo rotulado do dashboard. Isso não confirma a renderização, cliques, largura real de 390 px, perfil externo ou navegação por teclado. Consulte `docs/quality-gates.md` para os estados e evidências pendentes.

## Publicar no GitHub Pages

Envie os arquivos para a raiz da branch `main`. No repositório, abra **Settings > Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`, e salve. Aguarde o deploy e copie a URL exibida em Pages. O nome do repositório e o endereço final ainda precisam ser confirmados no seu GitHub.
